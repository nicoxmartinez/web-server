Referencia de Módulos Internos

El servidor se compone de abstracciones en src/lib/ para mantener una clara separación de responsabilidades.

Módulo del Server (server.h)

Encargado de inicializar, enlazar y escuchar peticiones HTTP en el socket.

Módulo de archivos (sendFile.h)

Se encarga del manejo de archivos estáticos, la construcción dinámica de cabeceras HTTP y el manejo de respuestas 404.
