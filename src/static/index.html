Arquitectura del Servidor

Este servidor web está desarrollado en C estándar (C11) implementando directamente sockets POSIX para la comunicación por red.

Estructura del Proyecto

        .
        ├── Makefile          # Automatización de build
        ├── Dockerfile        # Multi-stage Docker build
        └── src/
            ├── lib/
            │   ├── sendFile.c # Módulo de envío de archivos HTTP
            │   └── server.c   # Abstracción del Socket Server
            ├── main.c         # Punto de entrada
            └── static/        # Archivos estáticos

Ciclo de Vida de los Sockets

El flujo de la conexión sigue la secuencia nativa de red:

socket() ➔ setsockopt() ➔ bind() ➔ listen() ➔ accept() ➔ read() ➔ write() ➔ close()
