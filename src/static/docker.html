Contenedorización con Docker

El proyecto utiliza una estrategia de compilación en dos etapas (*Multi-stage*) para generar un contenedor de producción ultra ligero que contiene solo el binario C ejecutable y los archivos estáticos.

Comandos de Automatización

A través del Dockerfile puedes construir el contenedor fácilmente: 

        
          # Compilar la imagen
          docker build -t web-server .

          # Ejecución del contenedor
          docker run -p 8080:8080 --name mi_servidor web-server
